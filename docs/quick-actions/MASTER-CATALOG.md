# Master AI Quick-Action Catalog

This catalog defines the complete action surface for AI building, operating, testing, securing, and evolving AI systems.

## Build actions

- Create an application, API, dashboard, database, workflow, agent, swarm, skill, connector, documentation set, test suite, deployment package, or learning module.
- Convert a description, diagram, issue, lesson, or workflow into an implementation plan.
- Generate project structure, schemas, contracts, routes, components, prompts, policies, tests, and documentation.
- Convert an existing process into a reusable workflow or API.
- Create development, staging, and production configurations.

## AI-building-AI actions

- Design an AI system from requirements.
- Generate agent roles and responsibilities.
- Create a swarm topology and task-routing policy.
- Generate prompts, tool schemas, memory policies, evaluation sets, and fallback strategies.
- Create an AI skill from a successful procedure.
- Improve an existing prompt, workflow, API, agent, or evaluation.
- Compare multiple designs and explain tradeoffs.
- Create a safe experiment branch.
- Generate a migration plan and compatibility report.

## Evolution actions

- Analyze failures, feedback, logs, tests, and user outcomes.
- Propose a ranked improvement backlog.
- Detect duplicated, conflicting, obsolete, or unsafe capabilities.
- Run regression evaluations against previous versions.
- Compare model providers and routing strategies.
- Optimize cost, latency, quality, reliability, and security.
- Create a candidate change, test it in isolation, and prepare a review package.
- Learn from approved outcomes without changing production automatically.
- Create a versioned improvement record.

## Jarvis and swarm actions

- Create, clone, pause, resume, review, or retire an assistant.
- Create specialist roles for coding, research, QA, security, Linux, robotics, blockchain, education, business, and operations.
- Delegate a task to one agent or a swarm.
- Require independent review from another agent.
- Resolve conflicting recommendations.
- Share approved memory across a project.
- Restrict memory by user, project, portal, or sensitivity.
- Set budgets, time limits, tool permissions, and stop conditions.
- Approve, reject, retry, pause, or terminate a task.

## API and integration actions

- Discover an API.
- Generate an adapter, schema, SDK, webhook, or connector.
- Connect an approved provider.
- Validate credentials and scopes.
- Rotate or revoke credentials.
- Add retries, timeout handling, circuit breakers, queues, and provider failover.
- Mock an integration for testing.
- Run a health check.
- Generate integration documentation.
- Produce an API usage and error report.

## Quality and assurance actions

- Generate acceptance criteria.
- Generate unit, integration, contract, security, accessibility, performance, and regression tests.
- Run tests in isolation.
- Review code, prompts, workflows, permissions, data handling, and outputs.
- Check reproducibility and version compatibility.
- Compare candidate and baseline quality.
- Create a release report.
- Block a release when a gate fails.
- Prepare rollback and recovery steps.

## Security and governance actions

- Scan for secrets, unsafe dependencies, injection risks, excessive permissions, data leakage, and insecure defaults.
- Review agent tool access and network access.
- Check tenant and project isolation.
- Enforce data retention and deletion rules.
- Create audit records.
- Review sensitive content handling.
- Require approval for public, destructive, financial, credential, or production actions.
- Create an incident response plan.
- Verify backup and disaster recovery readiness.

## Operations and infrastructure actions

- Inspect health, logs, CPU, memory, storage, network, queues, and containers.
- Create a deployment plan.
- Deploy to an isolated environment.
- Promote after approval.
- Restart or recover a failed service.
- Scale workers.
- Verify DNS, SSL, webhooks, backups, monitoring, and alerts.
- Produce an infrastructure report.

## Education and business actions

- Create courses, lessons, labs, tutorials, challenges, assessments, ebooks, audiobooks, video books, and interactive demonstrations.
- Create learning paths and personalized recommendations.
- Generate business workflows, affiliate campaigns, membership features, onboarding, analytics, and reports.
- Convert technical work into documentation and educational content.

## Universal action contract

Every action must support validation, preview or dry-run, permission checks, risk classification, approval policy, timeout, retry policy, structured output, audit logging, verification, and rollback or recovery guidance.
