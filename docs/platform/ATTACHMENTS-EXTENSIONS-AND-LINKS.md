# Attachments, Extensions, and Quick-Link Governance

Attachments, extensions, integrations, downloadable resources, and quick links are first-class platform resources.

## Attachment types

- Educational documents
- Ebooks, audiobooks, and video books
- Code and configuration examples
- Robotics, wearable, Linux, blockchain, and AI resources
- API specifications and workflow templates
- Financial education and business documents
- Security reports and transparency reports

## Required metadata

Every attachment must have an owner, title, description, type, version, source, permissions, accessibility information, security scan result, review date, retention policy, and related portal or project.

## Extension requirements

Extensions must declare permissions, external services, data collected, storage locations, authentication method, failure behavior, revocation steps, and uninstall behavior. Extensions handling payments, wallets, trading, credentials, or personal data require security and compliance review before release.

## Link requirements

Quick links must use stable identifiers, preserve attribution where required, declare their destination type, and be monitored for availability and policy changes. Referral links must be clearly disclosed to users and must not be presented as impartial financial advice.
